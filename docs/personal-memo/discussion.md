# personal-memo 讨论记录

## 2026-11-05：改为能力参考

用户指出，默认使用“未分类”把本可由模型完成的归类推给用户；固定确认、环境检查、分页和输出限制也使一个小型备忘录过于机械。

本轮调整：

- 分类由模型理解内容后选择；已有分类提供参考，没有合适分类时可以新建，不设兜底分类。
- 将强制步骤改为能力说明与可组合的命令示例。
- 模型决定记录拆分、合并补充、检索策略和结果呈现；具体有歧义时再结合上下文处理。
- 环境探测作为首次接入或故障诊断工具，取消每次操作都完整检查的要求。
- 保留直接影响数据库正确性的知识：路径、字段、时间表示、引号处理和事务用法。

新库移除分类默认值。旧库的字段兼容，继续显式写入模型选择的分类即可，无需为本次技能修订迁移用户数据。
