# personal-memo

为智能体提供一个基于 SQLite（嵌入式关系数据库）的个人备忘录，默认保存在 `~/person.memo.db`。

## 概述

用户表达“记一下”“找一下”“补充一下”等意图，模型负责理解内容、选择分类、组织记录和调用数据库。技能提供能力和存储约定，让模型自行决定合适的操作方式。

支持个人资料和零散事项的增删改查、分类、关键词及时间检索。本版不包含后台巡检、提醒和多端同步。

## 工作流程

1. 理解用户意图，确定记录内容或要查找的信息。
2. 结合需要查看已有分类和相关记录，判断是新增、补充、修改还是其他操作。分类由模型决定，适合时复用已有名称，没有合适名称时建立新分类。
3. 选择命令参考中的操作并组合执行；首次记录时可初始化数据库，已有环境直接使用。
4. 根据执行结果继续检索或整理，向用户反馈所需信息和操作结果。

这是能力的典型组合方式，不是每次都必须走完的检查清单。记录粒度、正文组织、查询条件和结果详略交给模型判断。

## 已知问题

- SQLite 子串匹配区分大小写；模型可选择搜索词，但底层没有语义搜索索引。
- 创建与更新时间可以直接筛选；正文中的日期需由模型结合内容理解。
- 数据库默认不加密；并发编辑、大数据量与其他平台尚未全面验证。
- 旧数据库可以继续使用；技能更新不自动改写用户已有分类或记录。
