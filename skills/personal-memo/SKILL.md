# 个人备忘录

你可以用这个技能持久保存和整理用户的信息。理解用户想记住或找回什么，自行选择合适的记录方式与数据库操作。

## 存储与依赖

- 使用 SQLite（嵌入式关系数据库）的 `sqlite3` CLI（Command-Line Interface，命令行界面）和系统 Shell（命令解释器）。
- 默认数据库为 `$HOME/person.memo.db`，用户另有指定时使用其路径；数据跨项目复用。
- [命令参考](references/operations.md)包含依赖安装、初始化、查询、写入和备份示例，按需要查阅。环境已经可用时可以直接操作。
- [表结构](assets/schema.sql)用于创建新库；[能力探测](assets/probe.sql)可用于首次接入或排查命令兼容问题。

## 数据模型

`notes` 表包含 `id`、`category`、`title`、`body`、`created_at`、`updated_at`。

一条记录有一个分类、一个标题和自由组织的正文。时间统一存为 UTC（Coordinated Universal Time，协调世界时），修改时刷新 `updated_at`。

## 可以怎样使用

- **记录与整理**：根据内容提炼标题、选择有意义的分类，组织便于以后理解和检索的正文。已有分类和相关记录可帮助保持一致；适合时复用分类，没有合适分类时建立新分类。用户无需预先提供分类、标题或完整结构。
- **补充与更新**：结合已有内容判断是新增一条、补充原记录还是修正旧信息。记录粒度和组织方式服务于用户意图。
- **查找**：可以查看分类、搜索标题与正文、筛选创建或更新时间，也可以组合条件、换词或扩大范围继续查找。根据问题决定返回摘要还是详细内容。
- **删除与备份**：按用户意图定位记录或数据库，使用相应能力完成操作。

这些是可组合的能力。分类选择、信息组织、操作顺序、查询范围和结果详略由你结合上下文判断；需要用户补充的关键含义不明确时再询问。

命令参考中的示例可调整。留意文本转义、时间范围和实际执行结果，确保保存的信息与用户意图一致。
